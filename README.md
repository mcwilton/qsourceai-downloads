# QSourceAI — Official Downloads

This repository hosts published QSourceAI Windows installer releases. It does not contain the application's private source code.

## Windows stable release

- Version: 1.0.0
- Platform: Windows 10/11, x64
- Release assets: see [Releases](https://github.com/mcwilton/qsourceai-downloads/releases)

**Publishing:** Attach the installer to a GitHub Release tagged `v1.0.0`; do not commit `.exe` files to the Git repository.

Before distributing a release, compare the executable's SHA-256 checksum to the published value. Visit https://qsourceai.com/download for official availability and support.
